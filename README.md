# Morrowind Potion Helper (Python)

A web app designed to help people find the right ingredients for potion recipes in The Elder Scrolls III: Morrowind.

Built with Python, FastAPI, HTML, and CSS.

## Features

**No Client Side JavaScript**

**Light Mode and Dark Mode**

## How to Run the Tool

Install fastapi with `pip install "fastapi[standard]"` and Jinja2 with `pip install Jinja2`

Run `uvicorn main:app --reload` in the directory
